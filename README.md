# Mincraft

Игра в стиле Minecraft прямо в браузере — с компьютера и с телефона, без установки.
Можно играть одному или вместе с друзьями.

## Как играть

Откройте **https://mywebchel.github.io/mincraft/**, введите ник и нажмите «Играть».
Мир создаётся и сохраняется прямо в вашем браузере.

**Позвать друга:** в игре откройте паузу (`Esc` или кнопка «II» на телефоне) → «Пригласить друзей».
Отправьте другу ссылку или покажите QR-код — он откроет её на телефоне или компьютере и окажется
в вашем мире. Мир работает у вас, поэтому, пока друзья играют, не закрывайте игру.

Устройства соединяются напрямую (WebRTC). Открытый сервер [PeerJS](https://peerjs.com) только
знакомит их друг с другом; если прямое соединение невозможно, данные идут через его ретранслятор.
Лучше всего, когда вы в одной Wi-Fi сети.

## Что есть в игре

**Графика «как с шейдерами»**
- мягкие тени от солнца и луны, плавное освещение и затенение углов (AO);
- качающиеся на ветру листья, трава и цветы;
- вода с прозрачностью, отражением неба и бликами, вид из-под воды;
- небо с солнцем, луной и звёздами, объёмные облака, закаты и рассветы;
- свечение (bloom), лучи солнца, кинематографическая цветокоррекция;
- тёплый свет факелов и светокамня, полная смена дня и ночи, дождь.

Качество графики меняется в меню паузы: *Низкая* (для телефонов), *Средняя*, *Высокая*, *Ультра*.

**Мир**: равнины, леса, пустыни, снежные земли, горы, пляжи и океаны; пещеры с рудами
(уголь, железо, золото, алмазы) и лавой. Вода и лава растекаются, песок и гравий падают,
пшеница, саженцы и сахарный тростник растут, трава разрастается, на равнинах встречаются тыквы.
В снегах вместо дождя идёт снег, в пустыне осадков нет.

**Строительство**: доски, брёвна, камень, кирпичи, шерсть, стекло и стеклянные панели, плиты и ступеньки,
заборы и калитки, двери и люки, лестницы, факелы, светильники Джека, книжные полки, блоки из металлов.

**Выживание**: здоровье, голод, воздух под водой, урон от падения, огня и лавы; броня;
инструменты с прочностью (дерево, камень, железо, золото, алмаз); еда; лук и стрелы;
вёдра с водой и лавой; мотыга и грядки; костная мука; динамит и взрывы; кровать и сон
(точка возрождения); после смерти вещи выпадают на месте.

**Крафт и инвентарь**: инвентарь с крафтом 2×2 и слотами брони, верстак 3×3 (80+ рецептов, 70 блоков и 140 предметов),
**книга рецептов** (показывает, что можно сделать из того, что есть, и раскладывает ингредиенты одним нажатием),
печь с топливом и переплавкой, сундуки (общие для всех игроков), творческий инвентарь со всеми блоками.

**Мобы**: свиньи, коровы, овцы (можно стричь), курицы; ночью — зомби, скелеты с луками,
криперы и пауки. Нежить горит на солнце. С мобов падают ресурсы.

**Мультиплеер**: все видят друг друга, изменения мира, мобов и выброшенные предметы; общий чат;
мир, инвентари друзей и содержимое сундуков сохраняются у хозяина мира.

## Свой сервер (по желанию)

Если хочется, чтобы мир жил постоянно и не зависел от открытой вкладки, можно запустить
сервер на компьютере. Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000, введите ник и нажмите «Играть». Мир сохраняется в `data/world.json`.

### Играть вместе в одной Wi-Fi сети

В главном меню есть панель **«Играть вместе»** с адресом вида `http://192.168.0.10:3000` и QR-кодом.
Наведите камеру телефона на QR-код или откройте этот адрес на другом компьютере — и вы в одном мире.
Тот же адрес печатается в консоли в строке `Network:`.

Если с телефона не открывается — разрешите Node.js в брандмауэре Windows (частные сети)
и проверьте, что оба устройства в одной сети (не гостевой Wi-Fi).

Для игры с телефона удобнее собранная версия — она загружается быстрее, чем режим разработки:

```bash
npm run build
npm start
```

### Свой сервер в интернете

- **Быстро, без настройки**: временный туннель, например
  `npx cloudflared tunnel --url http://localhost:3000` — он выдаст публичную ссылку `https://…`,
  её можно отправить друзьям.
- **Постоянно**: разверните игру на хостинге с Node.js (см. ниже). В репозитории есть
  `Dockerfile` и `render.yaml` (Render: New → Blueprint → выбрать этот репозиторий).
  На бесплатных тарифах диск обычно не сохраняется — мир будет сбрасываться при перезапуске.

## Управление

| Компьютер | Действие |
| --- | --- |
| `WASD` / стрелки | ходить |
| `Пробел` | прыжок (в творческом ×2 — полёт) |
| `Shift` | присесть / вниз в полёте |
| `Ctrl`, `R` или `W` ×2 | бег |
| ЛКМ (удерживать) | ломать блок / бить |
| ПКМ | ставить блок, есть, стрелять из лука, открыть сундук/печь/верстак, лечь спать |
| колесо мыши, `1`–`9` | выбор предмета |
| СКМ | взять блок в руку |
| `E` | инвентарь и крафт |
| `Q` / `Ctrl+Q` | выбросить предмет / всю стопку |
| `T`, `Enter`, `/` | чат и команды |
| `Tab` | список игроков |
| `F5` | вид от первого / третьего лица |
| `F3` | отладочная информация |

**Телефон**: джойстик слева — ходьба, свайп по экрану — обзор, короткое касание — поставить/использовать,
долгое нажатие — ломать. Кнопки: «Бить», «Ставить», «Присесть», «Прыжок», «Инвентарь», «Чат».
В инвентаре: касание — взять/положить стопку, долгое нажатие — половину/по одному, двойное касание — перенести.
Удобнее всего держать телефон горизонтально и нажать «На весь экран» в меню паузы.

## Команды чата

`/help`, `/list`, `/tp <ник>`, `/spawn`, `/time day|noon|sunset|night|midnight|<0-23999>`,
`/weather clear|rain`, `/gamemode survival|creative` (или `/gm s|c`), `/give <предмет> [кол-во]`,
`/summon <моб> [кол-во]`, `/kill`, `/seed`.

Команды доступны всем игрокам — игра рассчитана на друзей. Входа по паролю нет: ник — это и есть
ваше сохранение, поэтому не давайте свою ссылку посторонним.

## Сервер для постоянной игры

```bash
npm run build
npm start
```

Переменные окружения:

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `PORT` | `3000` | порт HTTP и WebSocket |
| `DATA_DIR` | `data` | папка с сохранением мира `world.json` |
| `WORLD_SEED` | случайный | сид для нового мира |

Docker:

```bash
docker build -t mincraft .
docker run -p 3000:3000 -v mincraft-data:/data mincraft
```

## Как устроено

- `src/shared` — общий код клиента и сервера: блоки и предметы, генерация мира, освещение,
  физика, рецепты, протокол.
- `src/client` — браузерный клиент на Three.js (WebGL 2): мешинг чанков в веб-воркерах,
  рендер-конвейер с тенями и постобработкой (`render/`), интерфейс, звуки (синтезируются в WebAudio).
- `server` — ядро игры (`core.ts`): чанки, жидкости, мобы, предметы, печи и сундуки, игроки.
  Одно и то же ядро работает в двух местах: на Node-сервере (WebSocket, сохранение в файл) и прямо
  в браузере в веб-воркере (`src/client/host`), когда мир хостит сам игрок, — тогда друзья
  подключаются по WebRTC, а мир хранится в IndexedDB.
- Публикация: при каждом изменении ветки `main` GitHub Actions (`.github/workflows/pages.yml`)
  собирает игру (`npm run build`) и выкладывает её в ветку `gh-pages`, откуда её раздаёт GitHub Pages.
  Без сервера рядом игра сама переходит в режим «мир в браузере».
